# CHECKLIST_PRE_DEPLOY — Currículo Irresistível IA

Ações obrigatórias antes de publicar.

- [ ] Verificar se `SHEET_ID` está correto no Apps Script.
- [ ] Verificar se `SCRIPT_URL` e `PROXY_URL` estão corretas no HTML.
- [ ] Testar se o Cloudflare Worker responde (mesmo que com erro de chave).
- [ ] Validar se a aba `acessos` na planilha tem as colunas corretas.
- [ ] Garantir que o `GITHUB_TOKEN` tem permissões de escrita.
