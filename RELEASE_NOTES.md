# RELEASE_NOTES — 1.0.0-RC-1

Notas da primeira versão candidata à release (Release Candidate).

## Destaques
- Sistema completo de ponta a ponta funcional.
- Segurança garantida via Proxy Cloudflare.
- Controle de acesso robusto via Google Sheets.
- Documentação técnica e manuais de usuário exaustivos.

## Alterações nesta RC-1
- Auditoria completa de links e referências.
- Injeção de configurações oficiais (ID Planilha, URLs).
- Consolidação do Kit de Implantação.
- Geração do Protocolo de Handover.

## Limitações Conhecidas
- Dependência manual de configuração de chaves API no Cloudflare.
- Limite de 30 dias de acesso (hardcoded no Apps Script).
