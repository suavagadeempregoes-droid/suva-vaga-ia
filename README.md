# Currículo Irresistível IA — SUA VAGA DE EMPREGO

O **Currículo Irresistível IA** é uma ferramenta de alta performance projetada para ajudar candidatos a superarem os filtros automáticos (ATS) das empresas. Utilizando o **Método A.R.T.E.®**, a plataforma analisa a descrição da vaga e reformula o currículo do usuário, garantindo que as palavras-chave e competências corretas sejam destacadas.

## 🚀 Funcionalidades

- **Análise de Vaga:** Identificação automática de competências críticas.
- **Reformulação Estratégica:** Adaptação do conteúdo mantendo a voz do usuário.
- **Prontidão ATS:** Otimização para sistemas de triagem automática.
- **Geração de PDF:** Entrega de um currículo profissional pronto para envio.
- **Integração com Hotmart:** Controle de acesso e créditos automatizado.

## 🛠️ Stack Tecnológica

- **Frontend:** HTML5, CSS3 (Tailwind-like), JavaScript Vanilla.
- **Backend:** Google Apps Script (Controle de Acesso e Créditos).
- **Banco de Dados:** Google Sheets.
- **IA Proxy:** Cloudflare Workers + Anthropic Claude API.
- **Hospedagem:** GitHub Pages.
