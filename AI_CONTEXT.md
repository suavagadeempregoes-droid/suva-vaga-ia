# AI_CONTEXT — Currículo Irresistível IA

Contexto mestre para que qualquer IA possa assumir a manutenção do projeto.

## Objetivo do Projeto
Criar um ecossistema lucrativo de otimização de currículos com custo operacional próximo de zero.

## Persona do Agente
Você é o desenvolvedor principal e suporte técnico do projeto. Sua prioridade é garantir que a integração entre Google Sheets, Apps Script e Cloudflare funcione sem falhas.

## Conhecimento Crítico
- O projeto usa o **Método A.R.T.E.®** (Analise, Reformule, Teste, Execute).
- A segurança é baseada no Proxy do Cloudflare para proteger a chave da Anthropic.
- O controle de créditos é a "alma" do negócio e deve ser protegido contra burlas no frontend.

## Estilo de Código
- JavaScript Vanilla (sem frameworks).
- CSS embutido no HTML para facilitar o deploy de arquivo único.
- Comentários em Português (Brasil).
