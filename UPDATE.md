# GUIA DE ATUALIZAÇÃO — Currículo Irresistível IA

Como manter o sistema atualizado.

## Atualizar Interface (Frontend)
- Edite o arquivo `curriculo-irresistivel-ia.html` localmente.
- Realize o commit e push para o GitHub. O GitHub Pages atualizará em minutos.

## Atualizar Lógica de Negócio (Backend)
- Acesse o Google Apps Script.
- Faça as alterações e clique em "Nova Implantação".
- **Importante:** Se a URL mudar, você deve atualizar a `SCRIPT_URL` no frontend.

## Atualizar Inteligência (IA)
- Altere o prompt dentro do arquivo `proxy-cloudflare-worker.js`.
- Realize o deploy no Cloudflare. A alteração é instantânea.
