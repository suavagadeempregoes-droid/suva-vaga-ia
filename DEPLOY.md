# GUIA DE DEPLOY — Currículo Irresistível IA

Instruções para republicar o projeto.

## Via GitHub Pages (Recomendado)
1. Crie um repositório no GitHub.
2. Faça o upload de `curriculo-irresistivel-ia.html` e `pagina-vendas.html`.
3. Vá em Settings > Pages e ative a branch `main`.

## Via Servidor Próprio
1. Transfira os arquivos HTML para a raiz do seu servidor.
2. Certifique-se de que o servidor suporte HTTPS para evitar bloqueios de segurança nas chamadas de API.

## Verificação Pós-Deploy
- Acesse a URL pública e tente realizar o login com um e-mail de teste cadastrado manualmente na planilha.
